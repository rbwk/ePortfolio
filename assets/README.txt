ASSETS FOLDER
=============

Put your files here and the site will pick them up automatically:

  photo.jpg    -> optional profile photo for the About page
                  (then edit about.html: replace the <div class="avatar">NC</div>
                   line with: <img class="avatar" src="assets/photo.jpg" alt="Nathan Chu">)

You can also drop project images here and reference them from portfolio.html, e.g.:

  <img src="assets/my-project.jpg" alt="Description">

Keep file names lowercase with no spaces (use-dashes-like-this.jpg) so links work
reliably once the site is live on GitHub Pages.
