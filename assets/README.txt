ASSETS FOLDER
=============

Put your files here and the site will pick them up automatically:

  photo.jpg    -> optional profile photo for the About page
                  (then edit about.html: replace the <div class="avatar">NC</div>
                   line with: <img class="avatar" src="assets/photo.jpg" alt="Nathan Chu">)

  portfolio/   -> co-op work samples shown on goals.html (Work Portfolio section)
  coursework/  -> COOP 2100 essays, papers, and video shown on portfolio.html

Every slot in those two folders currently renders a placeholder instead of a real
file. Each placeholder has an HTML comment directly above it in the page showing
the exact markup to paste in once you drop the real file in place.

IMPORTANT: the boxes in the Work Portfolio section are marked "Confidential —
details available on request" on purpose. Only swap one for a real image or
document if that specific item has been cleared for public release. Leaving it as
a confidential notice is a valid permanent state, not an unfinished task.

Keep file names lowercase with no spaces (use-dashes-like-this.jpg) so links work
reliably once the site is live on GitHub Pages.
